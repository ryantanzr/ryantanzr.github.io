# ryantanzr.github.io

Personal site and tech blog, built with [Astro](https://astro.build) and deployed to GitHub Pages.

## Develop

```bash
npm install
npm run dev      # http://localhost:4321
npm run build
```

## Write a blog post

**Option 1: the writing UI (easiest).** Go to `https://ryantanzr.github.io/admin/`, sign in with a GitHub token, click **New Post**, write, and hit **Save**. It commits to `main` and the site redeploys in about a minute.

First-time sign-in needs a fine-grained token:

1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
2. Repository access: **Only select repositories** → `ryantanzr.github.io`.
3. Permissions → Repository permissions → **Contents: Read and write**. Nothing else.
4. Paste it into the "Sign in with token" box on `/admin`. The browser remembers it; revoke it from the same GitHub page whenever you like.

Tick **Draft** to save without publishing.

**Option 2: in your editor.**

```bash
npm run new-post -- "My post title"   # creates src/content/blog/my-post-title.md as a draft
npm run dev                            # preview at http://localhost:4321/blog/
```

Fill in `description`, set `draft: false`, then commit and push to `main`.

Images: drop them in `public/images/blog/` and reference them as `![alt](/images/blog/pic.png)`. (The writing UI does this for you.)

## Edit the rest

- Bio, experience, projects, skills: `src/data/site.ts` (and the About/Education text in `src/pages/index.astro`)
- Ink illustration: `src/components/InkHero.astro`; colours and theme in `src/styles/global.css`
- `public/admin/` holds [Sveltia CMS](https://github.com/sveltia/sveltia-cms) 0.253.2 (MIT), vendored unmodified; its field setup is `public/admin/config.yml`.

## Security and performance

- **Hosting/DDoS:** the site is fully static on GitHub Pages, so there is no server or database to attack. Traffic is served from GitHub's CDN, which absorbs volumetric DDoS. For rate limiting, a WAF, or real HTTP security headers you would put Cloudflare (free) in front of a **custom domain**; `*.github.io` itself can't be proxied.
- **CSP:** every page ships a strict `Content-Security-Policy` (`default-src 'none'`, nothing from other origins, script/style hashes generated by Astro; see `security.csp` in `astro.config.mjs`). Meta-tag CSP can't set `frame-ancestors`; the page hides itself if framed instead.
- **No third parties:** fonts are self-hosted (Lato, Minoru as WOFF2), no analytics, no CDN scripts.
- **Supply chain:** CI actions are pinned to commit SHAs, `npm ci --ignore-scripts`, Dependabot (npm + Actions), secret scanning with push protection, and force-push/deletion blocked on `main`.
- **Admin:** `/admin` (Sveltia CMS, vendored) runs under its own CSP. Use a fine-grained token limited to this repo with a short expiry.
- **Contact for vulnerabilities:** `/.well-known/security.txt`.
- **Speed:** about 45 KB for a first visit (HTML+CSS inline, 2 fonts, 2.5 KB of JS); particles load after first paint and are skipped on data-saver/low-end devices and with reduced motion.

## Deploy

1. Create a GitHub repo named `ryantanzr.github.io` and push this folder to `main`.
2. In the repo: Settings → Pages → Source: **GitHub Actions**.
3. Every push to `main` rebuilds and publishes the site.

If you use a different repo name, set `base: '/<repo-name>'` in `astro.config.mjs`.
